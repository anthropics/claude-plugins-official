Automated CI/CD & Security Workflows

The 9 GitHub Actions workflows securing and managing the official Claude Code plugins ecosystem.

Daily Cron / Dispatch

bump-plugin-shas.yml

Runs discover_bumps.py daily at 07:23 UTC against external repositories. Opens isolated PRs per plugin with a 60-bump daily budget.

Claude LLM Scan

scan-plugins.yml

Performs security and privacy reviews against Anthropic policy using Claude. Enforces zero cross-service credential leakage and maintains a 30-day verdict cache.

Required Gate

validate-plugins.yml

The primary merge-blocking check validating manifest JSON schema, strict commit-SHA pinning, and metadata rules.

Self-Healing

revert-failed-bumps.yml

Automatically reverts or drops failing external upstream versions from bump PRs so passing updates proceed immediately.

Network Test

check-mcp-urls.yml

Verifies that all Model Context Protocol (MCP) server endpoints declared in .mcp.json resolve and respond to health checks.

Scope Guard

external-pr-scope-guard.yml

Prevents external PRs from touching CI scripts, policy prompts, or internal plugins, ensuring PR changes remain strictly isolated.

Governance

close-external-prs.yml

Closes uncoordinated PRs and redirects partners to the official directory submission intake portal.

YAML Check

validate-frontmatter.yml

Executes validate-frontmatter.ts to ensure all SKILL.md documents contain compliant YAML headers.

Compliance

validate-licenses.yml

Scans for compatible open-source license files and ensures legal compliance across all listed packages.
