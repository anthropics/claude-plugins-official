# kotlin-lsp

Kotlin language server for Claude Code, providing code intelligence, refactoring, and analysis.

With the plugin enabled and `kotlin-lsp` on your `PATH`, Claude Code can use go-to-definition, find references, hover information, and diagnostics in Kotlin files.

## Supported Extensions
`.kt`
`.kts`

## Installation

Install the Kotlin LSP CLI.

```bash
brew install JetBrains/utils/kotlin-lsp
```
